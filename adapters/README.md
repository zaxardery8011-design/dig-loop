## 接頭範本

接一個新平台時，另寫一檔 `adapters/<平台名>.md`。照下面的欄填。沒做過的寫未驗。

- 平台名稱。
- 狀態。已驗。或未測，歡迎回報。
- 每天怎麼啟動。寫你實際點過或跑過的入口。
- 例行題貼到哪裡。
- 產出寫到哪。owner。repo。分支。
- 寫檔工具。把檔推上 main 用的那一個。
- 通知。不接也可以。
- 未驗。逐條寫。

填完在上面的表加一列。狀態照你實際測過的寫。
