# 第 3 課。填好例行題

這一課只做一件事。把例行題改成你的領域。

複製 [templates/routine_prompt.md](../templates/routine_prompt.md)。

改這四項。

- 池名。大寫英數。短一點。跟產出檔名、已解清單的池名欄一致。
- 領域一句話。
- owner。你的 GitHub 帳號或組織。
- repo。第 2 課那個產出庫的名稱。

分支維持 main。

具體問題由 bot 依那一句話自己挖。範本不附題目清單。

做完你會看到。題目裡的池名、領域、owner、repo 都是你的。池名不再是 `DEMO`。
