# 第 5 課。怎麼知道它真的做完

這一課只做一件事。用檔頭指紋確認這一格真的寫完。

指紋是產出檔第 3 行。它是第 4 行起直到檔尾的原始位元組的 SHA-256。64 字小寫十六進位。

三行怎麼寫、雜湊怎麼切。見 [docs/core.md](../docs/core.md)。

把產出庫 main 上的新檔拿回本機。路徑是 `inbox/dig/<YYYYMMDD>_<POOL>_r<round>c<cell>.md`。

在有 [tools/verify_header.py](../tools/verify_header.py) 的目錄執行。檔可以是拿回來的那一份。

```
python tools/verify_header.py <檔>
```

做完你會看到兩種結果之一。

印 `OK`。離開碼 0。第 3 行與第 4 行起的位元組相符。這一格可以送給人判斷。

印 `MISMATCH`。離開碼 1。不符。退回。不進判斷。少了行、第 3 行不是 64 位十六進位、或內文被改過，都是這個結果。

參數不是一個檔，或檔讀不到。離開碼 2。說明在標準錯誤。

想先看兩種印出長什麼樣。對夾具跑整夾核對。

```
python tools/verify_all.py tests
```

會印一行 `OK`、一行 `MISMATCH`。離開碼 1。[tests/fixture_ok.md](../tests/fixture_ok.md) 是對的。[tests/fixture_mismatch.md](../tests/fixture_mismatch.md) 是同一份只改一個字。第 3 行仍留舊雜湊。

人決定要做，而且做完之後。在產出庫 `requests/solved_list.md` 的 `## 清單` 下追加一行。再推回 main。清單留在本機。沒推回 main。下一輪仍會把同一個洞收回來。
