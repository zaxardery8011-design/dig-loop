# 第 0 課。複製就能用

這一課只做一件事。複製一段填空。填好。貼給自己的 Grok Bot。

1. 複製。下面有短版跟完整版。挑一版。
2. 填空。短版只填三格。做什麼。幾點。結果放哪。
3. 貼給自己的 Grok Bot。送到跟那個 bot 的對話裡。送出。

最後打開左側「自動化」。網址 `https://grok.com/automations`。清單上要多一列。bot 說建好了不算數。

2026-09-30 實測。說 7 點。清單上是 Every day at 6:50 AM。它會自己改時間。要整點就再跟它講。講完再看清單。

## 短版

只填三格。做什麼。幾點。結果放哪。

```
請幫我建立一條 Grok Bot Routine（不要先做別的）。

我在台灣。時區 Asia/Taipei。每天跑。

每天做什麼：________
幾點跑：__點__分（台北）
結果放哪：________

禁止：寄信、發公開貼文、刪檔、付款。除非我下面白紙黑字允許。
找不到資料時：回報原因。不要編造。不要湊數。
需要登入或授權時：停下來讓我接手。

請用我的話複述任務邊界。然後建立 Routine。回報例行名稱與下次執行時間。建好前先問我一個若答錯會改結果的問題。
```

## 完整版

底稿原樣。

```
請幫我建立一條 Grok Bot Routine（不要先做別的）。

【我是誰／時區】
- 我在：台灣，時區 Asia/Taipei
- 這條排程的名字我想叫：________

【要它每天做什麼（一句話）】
- ________

【什麼時候跑】
- 頻率：每天／平日／每週__（擇一）
- 時間：__點__分（台北）

【產出放哪】
- 只回覆這個對話／寫進某個檔或 inbox／其他：________
- 禁止：寄信、發公開貼文、刪檔、付款（除非我下面白紙黑字允許）

【成功長什麼樣】
- 做完我要看到：________（例如：下次執行時間、3 行摘要、檔案路徑）

【失敗怎麼辦】
- 找不到資料時：回報原因，不要編造、不要湊數
- 需要登入／授權時：停下來讓我接手

請：1) 用我的話複述任務邊界 2) 建立 Routine 3) 回報例行名稱與下次執行時間。建好前先問我一個若答錯會改結果的問題。
```
