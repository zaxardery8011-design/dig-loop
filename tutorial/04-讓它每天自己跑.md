# 第 4 課。讓它每天自己跑

這一課只做一件事。建一條每天跑的排程。把第 3 課的例行題放進去。

做法以 [adapters/grok-bot.md](../adapters/grok-bot.md) 為準。先走那一頁的「網頁」。

排程之前，GitHub 連接器要先完成一次授權。精確 OAuth scope 未驗。授權與寫檔工具見 [README.md](../README.md) 的從零設定。

然後做這幾下。這是一件事。

1. 打開左側「自動化」。網址 `https://grok.com/automations`。
2. 按「新自動化」。
3. 名稱填一個你認得的字。
4. 觸發器選每天。
5. 指示貼上第 3 課改好的例行題。
6. 按儲存。

通知有電子郵件與應用程式。不接也可以。不接也不影響挖洞與收件。

做完你會看到。新自動化的對話框有名稱、觸發器、指示、通知、儲存。觸發器選項裡有每天。

清單上既有的列會顯示名稱、排程、下一次執行、狀態。你按了儲存之後，自己這條會不會出現在清單上。未驗。

另一條路在接頭頁。在 bot 對話裡叫它自己建。那一頁也寫了兩件未驗的事。網頁改排程不生效。點 bot 名稱開 Routines。
