# 第 2 課。放好已解清單

這一課只做一件事。把已解清單放進一個專用的產出庫。

建議開一個專用 repo。建議 GitHub 授權只給那個 repo。私人庫。分支用 main。

從 [templates/solved_list.md](../templates/solved_list.md) 複製。放到產出庫的 `requests/solved_list.md`。

`## 清單` 下面有兩列虛構範例。保留會被當成已解。正式用前刪掉。

四欄怎麼寫。見 [docs/core.md](../docs/core.md)。

做完你會看到。產出庫 main 上有 `requests/solved_list.md`。`## 清單` 下面沒有那兩列範例。
